  - [HideAndSeekGameTest.kt](file:///Users/soroqn/me/private-code/Minecraft-FoMe/ExServerMod/src/test/kotlin/com/fome/exservermod/game/HideAndSeekGameTest.kt): Unit test suite verifying phase transitions, voting consensus, early search initiation, role swapping, and game resets.
